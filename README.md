# 33Bayan 🇩🇪

اپلیکیشن یادگیری آلمانی برای فارسی‌زبان‌ها — دیکشنری آلمانی ⇄ فارسی با تلفظ، تصویر، مثال و **جعبه‌ی لایتنر**، به‌همراه ترجمه‌ی متن.

ساخته‌شده با **React Native + Expo (SDK 58)** و Expo Router. مغز اپ (دیکشنری، بازبینی AI، لایتنر و ترجمه) همان بک‌اند ربات بله‌ی 33Bayan است که روی Vercel اجرا می‌شود:

- `GET /api/app?action=lookup&dir=de&q=Hund` — مدخل آلمانی (ویکی‌واژه + DWDS)
- `GET /api/app?action=lookup&dir=fa&q=سگ` — معادل‌های آلمانی
- `POST /api/app?action=translate` — ترجمه‌ی متن
- `leitner.*` — جعبه‌ی لایتنر کاربر (با شناسه‌ی دستگاه)
- تلفظ: `/api/tts?t=der+Hund&raw=1`

## اجرا

```bash
npm install
npx expo start
```

بعد با اپ **Expo Go** روی گوشی/تبلت، QR را اسکن کنید.

## صفحه‌ها

- **خانه** — ادامه‌ی یادگیری، هدف روزانه، روزهای پیاپی (Streak)
- **جست‌وجو** — دیکشنری دوطرفه با مدخل کامل و افزودن به لایتنر
- **تمرین** — مرور فلش‌کارت لایتنر + ترجمه‌ی متن
- **پیشرفت** — XP، توزیع خانه‌های لایتنر، نمودار هفته و نشان‌ها
- **پروفایل** — واژگان من، هدف روزانه و تنظیمات
